# Contribuidores

Quienes han hecho Boorie Cliente. [CONTRIBUTING.md](CONTRIBUTING.md) explica cómo contribuir.

## Otras contribuciones

Lo que no queda en el historial de git: pruebas, validación de versiones, conocimiento del
dominio, documentación técnica aportada… Se añade a mano, una línea por persona, con lo que
aportó.

- **Luis Mora** — prueba y valida cada versión antes de publicarla.

## Código

Sale del historial de git y **no se edita a mano**: se rehace con `npm run contribuidores`, que
es un paso del [proceso de release](PROCESO_DE_RELEASE.md). Si alguien aparece dos veces
—otro correo, otro nombre en otro equipo—, se juntan sus identidades en `.mailmap`, en la raíz
del repositorio, y se vuelve a generar.
